# 🌌 Multiverse of Chatbots

Welcome to **Multiverse of Chatbots** — an experimental project showcasing multiple chatbot personalities, architectures, and use cases, all unified under a single Streamlit interface.

## 🚀 Live Demo
Try it out here: [Multiverse of Chatbots](https://multiverseofchatbots.streamlit.app/)

## 📖 Overview
This project explores:
- Different conversational AI models and their unique styles
- How multiple chatbots can coexist in one interactive app
- Streamlit as a lightweight framework for rapid prototyping of AI interfaces

## 🛠️ Features
- Multiple chatbot personalities in one app
- Simple, intuitive UI powered by Streamlit
- Easy deployment to Streamlit Cloud
- Extensible design for adding new chatbot agents

## 📂 Repository Structure
multiverse_of_chatbots/
├── app.py              # Main Streamlit app
├── bots/               # Individual chatbot logic
├── utils/              # Helper functions
└── README.md           # Project documentation


## ⚡ Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/Mallesh06/multiverse_of_chatbots.git
   cd multiverse_of_chatbots
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   
3. Run the app locally :
   ````bash
   streamlit run app.py
   
   ````
